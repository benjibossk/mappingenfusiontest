# Roadmap

Stack: Vite + TypeScript, MapLibre GL, d3-delaunay, poisson-disk-sampling, simplex-noise, turf, proj4. 100% in the browser.

1. **Forests → Forest Generator**: draw/import forest polygons → export a shapes `.layer` with a native generator.
2. **Prefab auto-fill**: per-biome rules, Poisson-disk, hedges/rocks → entity `.layer`. Catalogue of vanilla prefabs (GUID).
3. **Countryside** (AgriFieldGenerator port): Voronoi parcels, hedges along borders, paths.
4. **Real world** (BARNMAP specs): area → DEM `.asc`, WorldCover + OSM → masks and shapes.
5. **Ground painting** (Map-generator + mapgen4 port): masks from terrain relief, live preview.
6. **Platform budget**: entity/density counter, alerts for Series S/X, PS5, PC.
